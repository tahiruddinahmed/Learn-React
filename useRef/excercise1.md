# Your first DOM ref practice
Now let's test whether you can use it, not just explain it.
Task: Focus and blur
Create a component called `SearchFocus.jsx`.

### Your requirements:
- Create a ref using `useRef(null)`.
- Attach the `ref` to an input.
- Create a button called `Focus Input`.
- Clicking it should focus the input.
- Create another button called `Blur Input`.
- Clicking it should remove focus from the input.

### Next challenge — Clear Input
Let's extend your existing component slightly to reinforce the concept.

Add a third button:`Clear Input`

When clicked, it should clear the input's text.

- Constraint: Do not use `useState` to store the input value for this challenge.
